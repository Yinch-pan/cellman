# 基础版对局交互本地验收

日期：2026-10-25。用户同意参考 BGA 大创造时代完成基础版，当前仅在本地验证，未发布公网。DIY 编辑器及自定义规则执行不属于本轮实现。

## 实现范围

- 开局：顺蛇/逆蛇轮抽，四类候选卡片、玩家选配结果表、地形起始说明、预选/取消反馈及明确的确认内容。
- 行动：阶段任务条、当前行动者/响应者、紧凑资源板、合法地图目标；保留已有建设、改造、升级、学者、公共行动、创新、特殊能力与自由转换。
- 后续选择：显示队列、来源与前后依赖；城市建筑群与奖励详情；桥位直接点击地图；明确放弃剩余收益。
- 回合与轮末：保留本回合试走、回退和统一提交；联机提交后仍需全员同意悔棋。自由转换可填入最大数量。结束本轮前提醒未用特殊行动，显示奖励板、下轮顺位及最后一轮差异。
- 终局：名次、总分、分项和资源换分算式；保留盘面、历史及战绩入口。

## 自动验收

### 规则及构建

- TypeScript 类型检查通过。
- 规则测试：30 个测试文件、176 项通过；含 3/4/5 人各 8 个种子的完整模拟和回放一致性，以及旧引擎回放。
- 前端生产构建通过。现有打包体积提示仍存在；未将其作为已完成的性能优化。

### 交互专项

28 项浏览器专项与回归测试通过，来自 `action-guidance.spec.ts`、`base-experience.spec.ts`、`snake-draft.spec.ts`、`turn-experience.spec.ts`、`selection-history.spec.ts` 和 `usability.spec.ts`。

覆盖：合法改造路径和资源不足、奥马尔初始塔楼、鼹鼠跨陆桥、创新书籍支付、公共铲子与建造、待选择期间自由转换、学科铲子限制、幻术师费用、两种轮抽及刷新、轮抽取消不写入、桥梁确认一次、城市奖励、结束本轮取消、手机结算、试走持久化与回退、整回合一次提交、教学路径。

补充回归验证了 320 像素窄屏的五位长用户名、手机快捷导航和预览确认按钮、终局禁止继续操作、学者槽默认值、历史记录加载、离线恢复与键盘帮助入口。

逆蛇完整验收首次在第 4 轮遇到测试定位歧义：书籍动作与特殊能力各有学科下拉框。现将前者明确命名为“书籍行动学科”，脚本使用确切名称；新增定向测试验证两种学科选择相互独立，书籍行动不会误用特殊能力目标或消耗其次数。该问题没有通过跳过行动来规避，修正后重跑完整逆蛇局。

主要手机验收视口为 390×844；截图检查页面宽度和卡片布局。截图证据在 `work/acceptance/base-interactions/`，包含 `draft-mobile.png`、`bonus-market.png`、`bridge-built.png`、`city-reward.png`、`final-mobile.png`；终局去掉选地提示后的最新截图在 `work/acceptance/base-final/`。

### 四账号完整对局

完整验收脚本为 `tests/e2e/four-player.spec.ts`，分别从顺蛇、逆蛇创建四人房间，四个独立登录会话中包含一个手机视口。测试通过真实按钮完成行动预览与提交，不直接写入游戏资源或结算状态。

每步比较四端服务器局面；中途让一个客户端断网、重连、刷新；结束后导出真实行动记录，再交给规则引擎回放并比较终局。

| 开局 | 提交数 | 六轮结果（p1 / p2 / p3 / p4） | 状态 |
| --- | ---: | --- | --- |
| 顺蛇 | 281 | 42 / 61 / 63 / 38 | 通过；四端一致、断线恢复、导出回放一致，无脚本错误 |
| 逆蛇 | 242 | 106 / 63 / 60 / 44 | 通过；四端一致、断线恢复、导出回放一致，无脚本错误 |

顺蛇局实际包含 16 次轮抽、8 次起始放置、75 次响应、15 次升级、6 次改造建造、14 次学者行动、14 次科技推进、18 次魔力公共行动、11 次书籍行动、1 次创新及 24 次结束本轮。证据保存在 `work/acceptance/base-full-games/snake-forward/`：`playthrough-summary.json`、`four-player-replay.json`、`four-player-finished.png`。

逆蛇局实际包含 16 次轮抽、8 次起始放置、54 次响应、17 次升级、8 次改造建造、13 次学者行动、11 次科技推进、14 次魔力公共行动、7 次书籍行动及 24 次结束本轮。证据保存在 `work/acceptance/base-full-games/snake-reverse/`，文件名同上。两局共 523 次真实 UI 提交，均正常完成六轮；加上专项与回归，本轮共 30 项浏览器验收通过。

测试使用单独测试数据库及随机 schema，端口可由 `E2E_WEB_PORT` / `E2E_API_PORT` 指定。本次完整局使用 5184/3012，专项使用 5185/3013，不占用用户已有的 5174/5175/5176 演示对局。

## 范围边界与待办

当前产品支持 3–5 人大地图；BGA 参考局为两人局，不能将其两人中立计分直接套入这里。当前没有声称双人小地图、全部种族组合或所有 BGA 功能逐项等价。

规则层完整模拟会用引擎筛选合法行动，能验证可完成性、状态约束与回放；它不是独立的规则正确性裁判。完整浏览器局同样不代表全部特殊能力组合都已实测。

更细的后续界面改进、尚未覆盖的 BGA 分支及 DIY 设计统一维护在 [对照清单](../bga-gameplay-ux-review.md)。本轮没有改动引擎版本或替换旧局规则。
