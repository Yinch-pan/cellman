# 地图直接建造与升级

2026-10-25，本地实现，未发布。

## 操作变化

此前常用路径：点建设页签 → 点地块 → 选择升级或改造表单 → 点击预览 → 在侧栏确认。

现在：点地图地块 → 在就近操作面板选择动作 → 在同一面板预览并确认。

- 工坊：直接显示“升级为公会”。
- 公会：并列展示学院、宫殿路径；已轮抽的宫殿直接使用固定 SH 编号。需要自行选择宫殿的旧开局配置展示各候选，不默认替玩家决定。
- 学院：直接显示“升级为大学”。
- 家园地形空地：显示“建造工坊”。
- 其他地形空地：显示“改造并建造工坊”和“先改造地形”。后者保留改造后的建造/放弃及资源转换流程。
- 不可执行选项显示具体原因并禁用，例如资源不足、超出可达范围。其他玩家和中立建筑不能升级。
- 可以按 Esc、关闭按钮或点击面板外退出；预览返回修改不改变对局。特殊移动与部分改造通过“详细设置”进入原有表单。

桌面面板靠近点击地块；手机采用底部面板，确认按钮位于底部快捷导航上方。面板可滚动，地图选择仍保持高亮。普通地图入口在建设/研究页签的本方主行动期间生效；公共行动已选目标、初始放置和待处理奖励沿用对应流程，避免把选桥位、铲子目标等变成普通建造。

## 规则与确认边界

候选动作通过现有版本化规则引擎校验。展示“结算后”的资源前后值，而非把含奖励的净变化错误地称为支付费用；最终预览继续列出得分、建筑与待处理响应。未复制费用计算或修改规则引擎。

地图入口与侧栏复用同一个预览和确认组件；只改变预览呈现位置。默认试走模式下确认步骤仍只改变私有计划，提交回合才公开；逐步提交模式仍只提交一次。断网、查看历史、等待他人、后续响应未完成时不开放新的地图主行动。

顺手修正旧宫殿下拉框将宫殿 ID 送入奖励板编号解析的错误，统一显示 SH 编号。

## 本地验收

23 项浏览器交互场景通过（原有 15 项 + 新增 8 项；初次失败的旧表单入口与手机测试地块修正后定向复测通过）。覆盖直接升级、分支与 SH 编号、直接改造建造、先改造后决定建造、手机试走/统一提交、取消、资源不足、他人建筑、不可达、键盘退出、详细设置，以及铲子、桥、革新、自由转换和原有手机快捷导航的回归。另验证“查看预览”不误关地图面板，以及改选河流会清掉陆地动作预览。
