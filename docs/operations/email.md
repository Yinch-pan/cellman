## 初次配置（QQ 邮箱）

1. 准备一个专门给 cellman 发信的 QQ 邮箱。在网页版 QQ 邮箱右上角头像 → 设置 → 账号与安全 → 安全设置中开启 POP3/IMAP/SMTP 服务、生成授权码。按官方页面要求完成身份验证。授权码不是 QQ 登录密码，不要发到聊天或写入仓库。官方说明：<https://help.mail.qq.com/detail/106/985>。
2. 在本机 PowerShell 执行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\yinch\Documents\Codex\BoardGame\scripts\configure-mail.ps1"
   ```

   按提示输入完整发信邮箱和 SMTP 授权码；授权码为隐藏输入。默认使用 `smtp.qq.com:465`，通过本机现有 SSH 密钥连接服务器。脚本通过 SSH 标准输入传输凭据，不将它们写入命令行或本机临时文件。也可用 `-SmtpHost`、`-SmtpPort` 指定另一个支持认证 SMTP 的服务（465 或 587）。
3. 配置脚本先验证 SMTP 连接、TLS 和认证，成功后保存服务器配置并重启 cellman；若激活失败则恢复原配置。**SMTP 验证不等于实际收件成功。** 登录 cellman → 账号设置 → 绑定一个能收信的邮箱 → 点击邮件链接并输入当前账号密码。检查收件箱及垃圾邮件，完成真实投递验收后再开启所需提醒。

专用 QQ 邮箱适合先验证小规模使用。若服务商限制发信或后续用户量增长，应迁移到事务邮件服务，并按供应商要求验证发信域名。网站仍可用当前 IP 地址访问，不必先更改网站域名。

## 服务器配置与维护

配置位于 `/etc/cellman/mail.env`，仅 root 可读（600），systemd 通过附加配置读取。包含 `MAIL_ENABLED`、`SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASS`、`MAIL_FROM`、`MAIL_TOKEN_KEY`。`MAIL_TOKEN_KEY` 为 32 字节随机密钥的 Base64，用于加密待发邮件内容；修改 SMTP 凭据时脚本保留此密钥。不要把真实配置复制进仓库、日志或对话。

未配置时 `MAIL_ENABLED=false`；网站提示邮件尚未启用，不能假装发送成功。可用 `GET /api/auth/mail-status` 查看是否已启用，但它不检测服务商当前是否可达。配置后若需停用，将 `MAIL_ENABLED` 改为 `false` 并重启 `cellman`；用户原有邮箱和偏好仍保留。

数据库备份包含邮件队列，但**不能代替配置密钥备份**。应将 `/etc/cellman/mail.env` 加密备份至受控位置；恢复数据库时同时恢复对应密钥。配置脚本保留上一份 root-only 配置 `/etc/cellman/mail.env.previous`。丢失密钥后原队列无法解密，可重新申请验证/重置链接；不要随意更换密钥。

链接有效期 20 分钟、一次有效。每个账号至少间隔 1 分钟申请，账号或收件地址每小时最多 5 次，入口另有 IP 限流。重置申请对不存在、限流及正常邮箱返回相同信息。明文链接仅用于邮件投递，数据库令牌只存摘要，待发邮件内容加密；发送后清空队列内容。

邮件任务每 15 秒检查一次；行动持续等待约 2 分钟后提醒，超时仍允许操作。每局同类提醒至少间隔 15 分钟，发信前再检查当前行动、协商暂停、邮箱及偏好，已处理的等待不再发送。失败退避重试，最多 5 次；提醒 1 小时后过期，验证/重置邮件随链接过期。投递属于至少一次语义：SMTP 接收后、数据库确认前发生进程崩溃，极少数情况可能重发。不会声称恰好一次。
