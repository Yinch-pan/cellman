## 验证中发现并修复的问题

1. 并发验收曾把所有模拟用户放在同一 IP，触发后加的防滥用预算；现仅在测试服务器信任 loopback，模拟独立客户端地址，生产代理信任规则未改。
2. 备份验收曾比较包含实时倒计时的响应，恢复期间时间推进导致失败；现在分别比较稳定局面与持久化时钟，仍验证恢复后可继续行动。
3. 注册浏览器脚本写死 5174，现遵守 `E2E_WEB_PORT`。一次运行受同时更新翻译文件引发的 Vite 重载影响；停止修改被测源文件后重跑，4 项通过。
4. DPAPI 文本末尾换行导致格式错误，读取时增加 Trim。初始 LocalAppData 配置又受打包桌面应用重定向影响，计划任务看不到配置；迁移到文档目录后通过真实任务验证。启动失败增加了不含凭据的诊断日志。
