# 对局全操作类别浏览器验收（2026-10-26）

本次按用户授权，使用 Playwright 驱动本机 Chrome，对当前本地版本逐项点击验收。仅本地修改和测试，未部署，也未推进用户原有对局 `88958d7a-2fa7-47ea-926f-27286e00c136`。

## 结论与边界

244 项去重浏览器用例通过（242 项专项和 2 场完整局）。新增专项脚本共 107 项，覆盖公共行动、支付、市场、响应、默认试走和手机入口。失败用例修正后重新运行，没有未解决失败。

这证明清单中的用户操作路径能够执行、取消并产生所断言的结果，不是“所有内容任意组合绝不出错”，也不是“与 BGA 所有规则和 UI 完全相同”。本次没有重新操作 BGA；比较基于已有 BGA 实机观察与当前本地实测。多本书批量选择、日志点击定位地图仍未实现。

### 四账号完整对局

两局均完成六轮正常终局，共 513 次界面提交：顺蛇 255 次，按座位得分 64 / 74 / 41 / 72；逆蛇 258 次，得分 66 / 71 / 54 / 67。两局均从注册、创建房间、加入、准备开始，后续行动经界面点击提交。每次提交检查四端一致，另检查刷新恢复、终局展示、导出记录重放与最终状态一致。两场终局截图已人工查看。

完整局采用详细确认模式，不以它替代默认试走验收。默认试走、撤销、私有计划对其他玩家不可见、整回合原子提交、双击只扣一次分别由专项验证。

## 测试方式与证据强度

- **实际浏览器**：项目 `channel: "chrome"`，独立上下文、无头运行，本机 Chrome；不是 DOM 单元测试或仅调用规则函数代替点击。
- **专项局面**：在隔离的演示存储中预先构造触发条件，然后实际点选按钮、输入付款、选择地图目标。读取存储和回放仅用于断言；不以直接调用提交接口代替被验收动作。
- **联机局面**：独立测试数据库与随机 schema，隔离端口 5191/3019、5194/3022 等；注册使用测试邮件接收器。部分网络/生命周期专项通过测试夹具安排边界状态，操作与结果仍由真实客户端验证。
- **完整局**：四个独立账号从网页注册开房后连续打六轮，非中途注入终局。用自动策略选择合法动作，故不能代表竞技策略质量或覆盖所有组合。
- 部分断言将界面结果与当前规则引擎比较，同时有固定费用/收益断言、四端一致性及重放检查；共享引擎的一致性不是独立的 BGA 规则正确性证明。
- 本轮开始时 39 文件/390 项规则、组件与目录基线通过；修复后相关布局/交互组件 13 项通过，类型检查、i18n 检查、生产构建通过。构建保留已有体积与第三方注释提示。

## 仍有差距

1. **多本书仍逐项选择**：每次选择能正确推进，尚无合并为一次多颜色分配的批量操作。
2. **日志不能直接定位地图**：历史查看/返回与导出可用，日志点击地块高亮尚未实现。
3. **手机科学轨道发现性**：可以横向滚到钥匙、收入和终点，但学科名会随内容移出视野，可后续固定学科名并增加滚动提示。
4. **手机纵向较长**：底部快捷入口可用，FAV 与全部公共信息仍需较长滚动；“可用”不等于已经和 BGA 一样紧凑。
5. **内容和规则边界**：当前主要为 3–5 人大地图；两人小地图、中立计分、全部官方编号、DIY 编辑器等既有差距未在本轮补齐。
6. **未穷举**：全部种族×宫殿×奖励×地形×革新组合、任意断线时刻、不同浏览器与真实手机触摸手势、生产负载和邮件投递不在本次证明范围内。
